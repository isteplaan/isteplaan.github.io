# Loo Kooli isteplaan

Loo Kooli õpetajatele mõeldud veebirakendus klasside isteplaanide loomiseks ja loosimiseks.

## Kavandatud võimalused

- sisselogimine Loo Kooli Google’i kontoga;
- ligipääs ainult `@lookool.ee` kasutajatele;
- keskne klasside ja õpilaste register;
- õpetaja valitud lemmikklassid;
- juhitud ja juhuslik istekohtade loos;
- lähestikku istumise piirangud;
- loosi eelvaade ja kohtade lohistamine;
- isteplaanide salvestamine ning PDF-eksport;
- administraatori klassinimekirjade import.

## Andmekaitse

Õpilaste andmeid ei salvestata lähtekoodi. Andmebaasis kasutatakse kasutajapõhiseid ligipääsureegleid ning õpetajate isiklikud isteplaanid ei ole teistele õpetajatele nähtavad.

## Olek

Rakenduse sõltumatu versioon on loomisel.
